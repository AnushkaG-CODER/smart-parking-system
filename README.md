# Smart Parking Management System

## About the Project

The Smart Parking Management System is a C++ based application
designed to simplify parking management.

## Main Feature
## Smart Slot Allocation

The system automatically assigns an available parking slot
according to the vehicle type.
Supported vehicle types:
- Car
- Bike
- EV

## Features
- Park Vehicle
- Smart Slot Allocation
- Display Parking Slots
- Remove Vehicle
- Search Vehicle
- Calculate Parking Fee

## Technologies Used
- C++
- Object-Oriented Programming
- Arrays
- Functions
- Linear Search

## Working
1. Enter vehicle number.
2. Enter vehicle type.
3. Check whether the vehicle is already parked.
4. Search for a suitable empty slot.
5. Automatically assign the slot.
6. Store the vehicle details.

## Complexity
- Time Complexity: O(n)
- Space Complexity: O(n)
